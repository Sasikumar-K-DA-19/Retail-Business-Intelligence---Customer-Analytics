# Retail Business Intelligence & Customer Analytics

## Project Overview
This project focuses on Retail Business Intelligence and Customer Analytics using the UCI Online Retail dataset.

The project uses Excel, Python, Pandas, Matplotlib and Power BI to analyse retail transaction data and present business information through dashboards.

## Tools & Technologies
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- Power BI

## Project Work
- Worked with the Online Retail dataset containing approximately 541,909 records.
- Performed data analysis using Python and Pandas.
- Used Excel for retail data analysis and dashboard creation.
- Created visualisations using Matplotlib.
- Developed a Power BI dashboard with four pages:
  1. Executive Overview
  2. Product Performance
  3. Customer Intelligence
  4. Market & Transaction Analysis

## Project Files
- Retail_Business_Analysis_01.ipynb – Python analysis notebook
- Retail_Business_Analytics.pbix – Power BI dashboard
- Excel Project Dashboard.png – Excel dashboard screenshot
- Power BI-01.png to Power BI-04.png – Power BI dashboard screenshots

UCI Online Retail Dataset:

## Project Objective
To explore retail transaction data, understand business performance and present analytical findings through interactive dashboards and visualisations.
